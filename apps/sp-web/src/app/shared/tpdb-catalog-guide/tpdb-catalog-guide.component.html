Using ThePornDB as your catalog

  1. Add your ThePornDB API token. Sign in at theporndb.net, create a token on your account's API Tokens page, then paste it into ThePornDB's settings here and Save & Test.
  2. Using Whisparr-Eros? Point it at Peeparr. Out of the box, Whisparr-Eros looks scenes up on StashDB, so with ThePornDB it has to use Peeparr's ThePornDB metadata instead. (Whisparr v2 already uses ThePornDB: skip this step.) On the machine running Whisparr-Eros, run:

    Use an address for Peeparr that Whisparr can reach (this is the one you're using now). The script backs up Whisparr's settings and restarts it. Running Whisparr in Docker, in another Proxmox container or over SSH? Add --docker <name>, --ctid <id> or --ssh <host>; see the deployment guide.
  3. Optional: ThePornDB's popular scenes. For the Popular lists, add your theporndb.net website login in Settings › Integrations once setup is done.
